My personal Nix Darwin Configuration
====================================

Nix-Darwin with Flake files for:

- macOS system configuration (by Nix-Darwin)
- User specific configuration (by Home Manager)

Installation
------------

A new computer setup.

1. Install Xcode
1. Install Nix package manager via [DeterminateSystems][2] or

   `curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install`

   with Option/Question "Install Determinate Nix" => **NO!**
1. Save this prepared configuration to `~/.config/nix`.
   Maintain a git repo for version control.
1. Read all the files in this repository, and understand what they do.
   1. If you have trouble understanding, [ryan4yin/nixos-and-flakes-book][3] is a good resource to learn nix and flakes.
1. Install Homebrew, see <https://brew.sh/>
   1. Homebrew is required to install most of the GUI apps, App Store's apps, and some CLI apps that are not available in nix's package repository `nixpkgs`.
1. Run the following command in the root of your nix configuration to build and activate it:

   ```bash
   sudo darwin-rebuild switch --flake .
   ```

   `darwin-rebuild` picks the matching configuration automatically by
   comparing your Mac's actual hostname against the folder names under
   [hosts/](hosts/) (see [Neuen Host hinzufügen](#neuen-host-hinzufügen)).
   If it doesn't match, or you want to build a specific host explicitly,
   use `sudo darwin-rebuild switch --flake .#hostname`.

Update
------

   ```bash
   nix flake update
   sudo darwin-rebuild switch --flake .
   # Because of the zsh shortcut simply use `switch` instead of the previous two lines
   switch # alias defined in home-manager/zsh.nix
   ```

Upgrade nix determine
---------------------

Manually from time to time

   ```bash
   sudo determinate-nixd upgrade
   ```

Brew cask
---------

Braucht es nicht, wird mit `switch` durchgeführt.

   ```bash
   eval "$(/opt/homebrew/bin/brew shellenv)"
   brew upgrade --greedy
   ```

Neuen Host hinzufügen
---------------------

`flake.nix` liest `hosts/` aus und baut daraus automatisch alle
`darwinConfigurations` — es muss dafür nicht angefasst werden.

1. Neuen Ordner anlegen, z.B. `hosts/MeinLaptop/`.
1. Darin eine `default.nix` mit den Host-Metadaten anlegen:

   ```nix
   {
     hostname = "MeinLaptop";
     username = "lukas";
     system = "aarch64-darwin"; # aarch64-darwin oder x86_64-darwin
     stateVersion = "25.05";
   }
   ```

1. Optional: eine `hosts/MeinLaptop/configuration.nix` anlegen, wenn dieser
   Host zusätzliche oder andere nix-darwin-Einstellungen braucht (z.B.
   andere Homebrew-Casks oder abweichende `system.nix`-Werte für andere
   Hardware). Diese Datei wird automatisch mit eingebunden, wenn sie
   existiert — sonst nutzt der Host einfach die gemeinsamen Module unter
   `modules/`.
1. Committen und auf dem neuen Rechner `sudo darwin-rebuild switch --flake .`
   ausführen — der Hostname der Maschine entscheidet automatisch, welche
   Konfiguration greift.

Home-Manager-Konfiguration (`home-manager/`) ist aktuell bewusst für alle
Hosts gemeinsam, da bislang derselbe User/dieselben Präferenzen auf allen
Maschinen gelten sollen. Falls das mal pro Host unterschiedlich sein soll,
ist die naheliegende Erweiterung ein `hosts/<name>/home.nix`, das
`home-manager/default.nix` importiert und host-spezifisch ergänzt.

Configuration Structure
------------------------

Your current nix-darwin configuration's structure should be as follows:

   ```bash
   › tree
   .
   ├── flake.lock          # a lock file generated by nix, you can ignore it for now
   ├── flake.nix           # entry point; discovers hosts/ and builds darwinConfigurations
   ├── hosts                # one folder per machine
   │   └── BettyBlue
   │       ├── default.nix        # hostname/username/system/stateVersion
   │       └── configuration.nix  # optional, host-specific nix-darwin overrides
   ├── modules             # shared nix-darwin (system-level) configuration files
   │   ├── apps.nix        # homebrew & nix apps (both GUI & CLI)
   │   ├── host-users.nix  # hostname & system users
   │   ├── nix-core.nix    # nix's core configuration
   │   └── system.nix      # macOS system configuration (dock, trackpad, keyboard, finder, ...)
   ├── home-manager         # shared user-level configuration, managed by Home Manager
   │   ├── default.nix     # entry point, imports the other home-manager modules
   │   ├── packages.nix    # general user packages (node, bun, pnpm, ...)
   │   ├── zsh.nix         # zsh configuration (aliases, completion, plugins)
   │   └── git.nix         # git configuration
   ├── docs                # supplementary notes (e.g. Apple container)
   ├── .github/workflows   # CI (flake-checker)
   ├── TODO.md             # open ideas / setup TODOs, not part of the setup docs
   └── README.md
   ```

Adoption
--------

Use this as a base and modify the configuration for other environments.

1. Follow the [Installation](#installation) steps above.
1. Under [hosts/](hosts/), replace `BettyBlue` with your own hostname and adjust `username`/`system` in its `default.nix` (see [Neuen Host hinzufügen](#neuen-host-hinzufügen)).
1. In [home-manager/git.nix](home-manager/git.nix), replace the hardcoded git name/email with your own.
1. Adjust [modules/apps.nix](modules/apps.nix) to the casks/brews you actually want.
